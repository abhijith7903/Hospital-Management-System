# Hospital Pre-Booking and Management System

## Description
The Hospital Pre-Booking and Management System is a web-based application developed to streamline hospital appointment scheduling and patient data management. The system reduces manual workload and improves administrative efficiency through secure database operations.

This project was developed as part of an academic team project and published in an international journal.

## Key Features
- Patient appointment pre-booking
- Efficient patient data management
- CRUD operations for hospital records
- Secure database connectivity
- Improved administrative workflow efficiency

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL
- XAMPP

## Project Details
- Team Size: 4
- Duration: 3 Months

## How to Run the Project
1. Clone the repository: git clone https://github.com/abhijith7903/Hospital-Pre-Booking-and-Management-System.git
2. Install XAMPP and start Apache & MySQL
3. Import the provided database file into phpMyAdmin
4. Move the project folder to `htdocs`
5. Run the application using `localhost` in a browser
